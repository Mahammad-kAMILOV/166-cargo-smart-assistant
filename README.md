# 🚚 166 Logistics Smart AI Assistant (RAG Prototype)

A Python-based prototype demonstrating a **Retrieval-Augmented Generation (RAG)** architecture designed for cargo and courier tracking systems at **166 Logistics**.

## 🎯 Key Features
- **Data Handling:** Implements Python Dictionaries and Lists for internal database simulation.
- **Data Normalization:** Uses String formatting (`.strip()`, `.upper()`) for clean tracking ID handling.
- **RAG Architecture:** Prevents AI **Hallucination** by fetching real database context before response generation.
- **Prompt Engineering:** Enforces domain constraints to provide accurate, business-safe customer responses.

## 🛠️ Tech Stack
- Python 3.x
- Prompt Engineering & RAG Concepts
